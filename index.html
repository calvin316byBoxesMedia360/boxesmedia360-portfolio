Especialidades bajo los departamentos existentes

Los briefs departamentales tienen estado “Propuesto · Fase 1”. Roles lógicos no son subagentes configurados.

Identidad / Diseño gráfico · Design

Entrada: brief, marca/activos originales, referencias autorizadas, canal, tamaño, texto exacto, derechos y límites.

Fuente editable: según la herramienta comprobada: SVG estructurado, archivo nativo de diseño realmente creado, etc.; los logos aprobados se colocan desde el master y no se redibujan sin permiso. Export: PNG/JPG/PDF según destino.

Herramientas: Pillow y Chromium probados en pilotos locales; Krita instalado; vector editor no confirmado en esta revisión. QA: ortografía/números, safe margins, identidad, contraste móvil, dimensions/resolution, source→export y fuentes/licencia. Cambiar maestros o marca: Calvin.

Dirección de arte / Publicidad · Design + Marketing

Entrada: objetivo/audiencia/canal, oferta confirmada, brand assets, copy/CTA, claims permitidos.

Entregables: concepto/storyboard/mood references, arte fuente y exportaciones por ubicación. Marketing dueño de copy/posicionamiento, Design dueño del arte.

QA: una idea dominante, oferta y fotografía concordantes, CTA viable, no claims no probados, exclusions, legibilidad y recortes. Publicación requiere Calvin.

Web / UI/UX · Product + Design + Operations

Entrada: usuario/tarea, estructura de contenido, journeys, responsive breakpoints, states, legal/accessibility, master identity.

Entregables: editable Figma/native file si herramienta disponible, o HTML/CSS/JS fuente; exports/screenshots solo supporting. Operations es responsable de integración/deploy autorizados.

Herramientas verificadas: browsing/read-only screenshots para estas páginas; HTML prototype skills disponibles, no implica testing. QA: viewport, keyboard/touch, pause/reduced motion, navigation, actual links, forms without submission. Deploy/publication gate.

Preprensa / Señalética · Product → Design → Operations → Growth/Quality

Entrada: dieline, material/proceso/supplier spec, medidas, tolerancias, sight distance, printer specs/profile/bleed/cut lines.

Fuente/export: native authoring file plus production PDF/vector/raster per supplier; never claim print-ready on PNG/web preview. Manufacturing by approved provider/human.

QA: preflight PDF, embedded/licensed fonts or outlined text, ICC/CMYK, scale, bleeds, contrast, QR scan test, proof/photo physical sample. Software and vendor/preflight unverified; external manufacturing approval by Calvin.

Imagen / Composición · Design

Entrada: original photo/product, exact identity/ingredients/shape constraints, crop target, retouch scope, intended use.

Entregable: source original unchanged, layered/editable composite only if layers actually exist, lossless or specified export + provenance. AI generation distinct operation needing separate authorization.

Tools: Krita installed, Pillow tested in prior pilot; generation/local models not verified. QA: pixels/identity, perspective/light, alpha edges, no invented product attributes, crop vs source, dimensions/profile and before-after.

Video / Motion · Design + Marketing + Operations + Growth/Quality

Entrada: objective, exact asset/copy, run time, aspect ratio, fps, audio/rights, safe margins, target screens/platform.

Source: editable timeline/project from an actual verified motion app; export MP4/MOV separately. FFmpeg proven for assembly/encoding, not editable keyframe project; no motion-authoring app verified here.

QA: temporal viewing, frame readability, text duration, transitions, audio/sync, decode/probe, crop. A sampled still cannot pass motion QA. New footage/generation not authorized here.
